# 🚀 Complaint AI

An AI-powered Customer Complaint Management System built using **Flask**, **Google Gemini AI**, **Machine Learning**, **SQLite**, and **Bootstrap 5**.

The application helps customers register complaints, receive AI-powered support, analyze complaint severity, and automatically generate complaint tickets.

---

# ✨ Features

- 🤖 AI-powered Customer Support Chatbot
- 🎫 Automatic Complaint Ticket Generation
- 🆔 Unique Ticket ID Generation
- 📧 Email Notification after Ticket Creation
- 📊 AI Complaint Analysis
- 😊 Sentiment Analysis
- ⚠️ Priority Prediction
- 📂 Complaint Category Prediction
- 🔍 Dispute Risk Prediction using Machine Learning
- 👤 User Authentication System
- 👨‍💼 Admin Dashboard
- 📈 Complaint Analytics Dashboard
- 📜 Complaint History
- 🌙 Dark / Light Theme
- 🎤 Voice Input
- 🔊 Text-to-Speech Responses
- 📱 Responsive UI

# 📊 Machine Learning

The project uses a trained Machine Learning model to predict:

- Complaint Category
- Complaint Priority
- Sentiment
- Dispute Risk

Models are serialized using **Joblib** for fast predictions.

---

# 📧 Email Notifications

After successful complaint registration, the system automatically sends:

- Ticket ID
- Complaint Confirmation
- Support Details

to the customer's registered email address.

# 💻 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Complaint-AI.git
```

Go into the project

```bash
cd Complaint-AI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
