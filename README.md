# Complaint AI

An AI-powered Customer Complaint Management System built using Flask, Gemini AI, Machine Learning, SQLite and Bootstrap 5.

---

## Overview

Complaint AI is an intelligent customer support platform that helps businesses automate complaint handling. The system analyzes customer complaints, predicts priority, detects sentiment, estimates dispute risk, and assists customers through an AI-powered chatbot.

---

## Features

- AI-powered chatbot using Gemini AI
- Automatic complaint ticket generation
- Unique Ticket ID generation
- Sentiment Analysis
- Complaint Priority Prediction
- Dispute Risk Detection
- Customer Dashboard
- Admin Dashboard
- Customer Management
- Complaint Analytics Dashboard
- Complaint Status Tracking
- Email Notifications
- Chat History
- Responsive Modern UI
- Dark Mode Support
